# Development setup

## Requirements

- Rust stable (minimum supported version: 1.89).
- Python 3.11 or later and [uv](https://docs.astral.sh/uv/).
- Optionally [just](https://just.systems): the [justfile](../../justfile) names the commands below (`just check` runs the local checks and tests; CI also builds and tests the wheels on every platform).

## Setup

```bash
uv sync --group dev          # creates .venv and builds the extension in release mode
uv run maturin develop -r    # rebuild after Rust changes
```

## Checks run in CI

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
uv run ruff check . && uv run ruff format --check .
uv run mypy
uv run pytest
python tools/checks/check_links.py .
python tools/checks/check_native_dependencies.py univo-python univo-engine
python tools/fixtures/build_critical_corpus.py --check
uv run pytest tests/tools
```

Linux wheels can be checked without CI, with Docker: `just linux aarch64 target/default-model` builds the manylinux wheel of the committed HEAD and runs the installed-wheel suite in Python 3.11 and 3.14, without Rust and as a non-root user. `just linux x86_64` does the same under emulation on Apple silicon, where timing budgets may need a rerun.

Wheel checks:

```bash
uv run maturin build --release --out dist
python tools/checks/check_wheel.py dist/*.whl
```

## Performance tests

Budgets live in [benchmarks/budgets.toml](../../benchmarks/budgets.toml). Python tests marked `perf` enforce them (`uv run pytest -m perf`); Rust budget tests run in release builds only (`cargo test --release`). Benchmarks: `cargo bench -p univo-core`.

Dense exact-index insertion: `cargo test -p univo-engine --release --locked --test perf_budget -- --nocapture` reports one-batch and single-record insertion at 10k/20k/40k, with and without IDs, and enforces the insertion budget in CI.

Embedding: tests that need the default model run only when `UNIVO_TEST_MODEL_DIR` names a directory holding its `config.json`, `model.safetensors` and `tokenizer.json`; they verify the pinned checksums first. CI downloads the pinned revision. Locally, rebuild it from its upstream source (a 434 MB download, about 7 s of conversion, checked against the same checksums):

```sh
export UNIVO_TEST_MODEL_DIR=.models/default
python tools/build_default_model.py --output "$UNIVO_TEST_MODEL_DIR"
cargo test -p univo-embed --release --locked --test perf_budget -- --nocapture
```

`UNIVO_TEST_HUB=1` enables the one test that uses the network. It downloads the pinned default model from the real Hugging Face hub into an empty cache with `python -m univo.models download`. It then checks the compiled checksums and runs a semantic `Finder` offline, with sockets forbidden. CI's wheel tests set it on every platform.

## Test models

`tests/fixtures/models/tiny` is an 8-dimension Model2Vec model with a 13-word vocabulary, built by `python -I tools/fixtures/build_tiny_model.py`. It exercises loading, encoding and the cache without a download.

## Unicode fixtures

`tests/fixtures/unicode` holds CPython's NFC and case folding results, the oracle of the Rust normalizers. Regenerate them with `python -I tools/fixtures/build_unicode_fixtures.py` when the Unicode version changes, and increment `NORMALIZER_VERSION` if any output changes. See [performance.md](performance.md) for the measurement policy.

## Troubleshooting

On macOS, Python 3.13 and later skip `.pth` files that carry the `hidden` file flag, which breaks editable installs (`ModuleNotFoundError: No module named 'univo'`). Clear the flag with `chflags -R nohidden .venv`.

## Layout

| Path | Role |
| --- | --- |
| `crates/univo-core` | Values, schema, normalization, record preparation and exact matching; no Python, network or inference dependency |
| `crates/univo-embed` | Model references, pinned registry, download plans, verified cache and static inference; no network access |
| `crates/univo-engine` | Record store and typed IDs, the [exact index](../design/exact-index.md), [lexical candidates](../design/lexical-search.md), [vector search](../design/vector-search.md), [search](../design/search.md) by score with its exhaustive oracle, reports, groups and snapshots |
| `crates/univo-python` | PyO3 extension `univo._univo`; conversions only |
| `crates/univo-testkit` | Unpublished test helpers shared by the crates: the critical corpus |
| `python/univo` | Public Python package |
| `tests/python` | Tests of the installed package, run on every platform, including `perf` budget checks |
| `tests/tools` | Tests of the repository tools and of the critical corpus, run once |
| `benchmarks/budgets.toml` | Single source for enforced resource budgets |
| `tests/fixtures/critical` | Critical corpus, generated by `tools/fixtures/build_critical_corpus.py` |
| `tools` | Repository checks, fixture generators and the quality pipeline |
