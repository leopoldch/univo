# Development

## Requirements

- Rust stable (minimum supported version: 1.86).
- Python 3.11 or later and [uv](https://docs.astral.sh/uv/).

## Setup

```bash
uv sync --group dev          # creates .venv and builds the extension in release mode
uv run maturin develop -r    # rebuild after Rust changes
```

## Checks run in CI

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
uv run ruff check . && uv run ruff format --check .
uv run mypy
uv run pytest
python tools/check_links.py .
python tools/check_native_dependencies.py univo-python univo-engine
python tools/build_critical_corpus.py --check
uv run pytest tests/tools tests/corpus
```

Wheel checks:

```bash
uv run maturin build --release --out dist
python tools/check_wheel.py dist/*.whl
```

## Performance tests

Budgets live in [benchmarks/budgets.toml](../benchmarks/budgets.toml). Python tests marked `perf` enforce them (`uv run pytest -m perf`); Rust budget tests run in release builds only (`cargo test --release`). Benchmarks: `cargo bench -p univo-core`.

Dense exact-index insertion: `cargo test -p univo-engine --release --locked --test perf_budget -- --nocapture` reports one-batch and single-record insertion at 10k/20k/40k, with and without IDs, and enforces the insertion budget in CI.

## Unicode fixtures

`tests/fixtures/unicode` holds CPython's NFC and case folding results, the oracle of the Rust normalizers. Regenerate them with `python -I tools/build_unicode_fixtures.py` when the Unicode version changes, and increment `NORMALIZER_VERSION` if any output changes. See [performance.md](performance.md) for the measurement policy.

## Troubleshooting

On macOS, Python 3.13 and later skip `.pth` files that carry the `hidden` file flag, which breaks editable installs (`ModuleNotFoundError: No module named 'univo'`). Clear the flag with `chflags -R nohidden .venv`.

## Layout

| Path | Role |
| --- | --- |
| `crates/univo-core` | Values, schema, normalization, record preparation and exact matching; no Python, network or inference dependency |
| `crates/univo-engine` | Schema-bound exact index, typed IDs, atomic batch insertion and bounded exact-search output; see [exact index](exact-index.md) |
| `crates/univo-python` | PyO3 extension `univo._univo`; conversions only |
| `python/univo` | Public Python package |
| `tests/python` | Tests of the installed package, run on every platform, including `perf` budget checks |
| `tests/tools` | Tests of the repository tools, run once |
| `tests/corpus` | Integrity of the critical corpus, run once |
| `benchmarks/budgets.toml` | Single source for enforced resource budgets |
| `tests/fixtures/critical` | Critical corpus, generated by `tools/build_critical_corpus.py` |
| `tools` | Repository checks and generators used by CI |
