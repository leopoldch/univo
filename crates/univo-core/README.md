# univo-core

Core types and matching logic of [Univo](https://github.com/leopoldch/univo), independent of any binding, network client or model:

- values and schemas, with typed IDs, partitions, text and exact fields;
- Unicode normalization and record preparation;
- pairwise scoring over exact, lexical, semantic and acronym evidence, with explanations;
- the typed errors every binding shares.

See the [documentation](https://github.com/leopoldch/univo/blob/main/docs/README.md). This crate is pre-alpha and not published yet.
