# univo-embed

Local embedding models for [Univo](https://github.com/leopoldch/univo):

- model references;
- a registry pinned by revision and checksum;
- download plans that the binding executes, since this crate makes no network access;
- a verified cache;
- static Model2Vec inference.

See [models, cache and offline use](https://github.com/leopoldch/univo/blob/main/docs/guide/models.md). This crate is pre-alpha and not published yet.
